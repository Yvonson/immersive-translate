安装与修复

先将伴随程序 ZIP 完整解压到一个文件夹，在该文件夹打开 PowerShell，执行下方命令。安装窗口会引导导入本地英汉词库资源包（dictionary-core.zip）。

命令已包含当前扩展 ID。移动扩展目录或换浏览器后，可重新执行此命令修复注册。资源包不会打包进浏览器扩展。

& "$env:LOCALAPPDATA\OpenBilingualTranslate\Companion\dictionary-companion.exe" --manage

再次导入或校验资源可运行上方管理命令。更新资源后点击“重新连接”。

发音与学习

释义、音标和例句在本地查询。点击播放后，在线语音仅接收当前单词或短语；无需录音包或离线语音模型。

默认优先使用可用的 Google 音色，缺失时使用同口音的系统音色。列表标明在线／本机；Chrome 和 Windows 的音色由实际环境决定。

需启用 Cloud Text-to-Speech API 并开通结算。使用 Standard 音色；免费额度与超额费用以 Google 官方价格为准。Key 只存本地，不进入普通配置导出。建议限制 Key 仅可调用此 API。

使用已保存的语音服务。多音词请结合音标与义项学习。

查词不调用翻译接口；在线发音会发送当前单词或短语。默认不保存查词历史；词条来源链接只在点击时打开。
