## D-005：统一原文保留渲染与 Chrome 快捷键

- 日期：2026-10-17。
- 状态：按用户确认的修订计划实现；真实 Chrome 全面验收待补。
- 依据：用户明确要求 Ctrl 单段切换、原文保留和译文格式；本轮仅 Chrome。
- 决定：整页、Ctrl 和文字稿共享段落记录；双语路径不替换原文节点，安全重建译文行内标签；损坏格式只向同一引擎按片段重试。
- 快捷键：单键和网页组合键在插件内配置，Chrome 绑定只读取并提供原生管理入口；相同按键只执行一次。
- 影响：替换旧复制原文再修改源节点的主路径；复杂站点需要回归。配置初始化先兑现 Promise，防止单个启动回调异常使翻译永久等待。
- 证据：`pageTranslator.js`、`reading-options.js`、浏览器测试；详细约定见 [升级说明](../READING-UPGRADE.md)。

- 日期：2026-10-17。
- 状态：用户反馈后已复现并修复；补充 D-005。
