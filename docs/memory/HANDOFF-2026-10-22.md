## 4. 已实现的网页翻译、引擎与界面

### 阅读与快捷键

- 原始 DOM 保留，译文放在原文下方，继承段落排版并安全重建可保留的行内格式；不是把原文节点直接改成译文。复杂站点 CSS 仍须真实页面回归。
- 鼠标所在段落单按并松开 Ctrl 可单独切换，其他段落保持状态；默认整页 `Alt+Shift+T`。快捷键可在插件内配置，Chrome 原生绑定另有管理入口。
- 忽略输入框／可编辑区域、输入法组合、长按重复；Ctrl+C、组合键和 Ctrl+点击不应顺带触发单段翻译。网页与原生路径去重。
- 共享段落记录、动态内容、错误和重试；鉴权／配置错误或重复失败停止无意义重试。格式失败仅用同一引擎进行受控片段重试。

### 翻译服务与密钥

- 内置 Google／Yandex；Google 公共服务无需自配 Key，但依赖网络和接口可用性。
- 用户可自行配置 DeepSeek、兼容 OpenAI Chat Completions 的服务，以及 Ollama／LM Studio 等本地服务。模型名与地址必须匹配实际安装／账户，不将默认值当作永久可用保证。
- AI 请求使用 `/chat/completions`、`stream: false`，要求返回与输入同序、同长度的 JSON 字符串数组；拒绝错位输出。已有分批、最多两路请求、25 秒超时、取消和内存缓存。精确限制以 `aiProviders.js` 为准。
- 服务由用户选择，不能在出错时偷偷把文本发送给另一家。发布审查还修掉了旧入口的自动换服务行为。
- `aiProviderSettings` 独立保存在扩展 `chrome.storage.local`，不进入普通设置导出、源码或 Git；本地扩展存储不是系统加密保险箱。Google Cloud 语音密钥独立管理，同样不回显／不混入普通配置导出。
- 远程端点使用 HTTPS，本机服务允许 localhost HTTP。真实付费 API 与本地模型端到端尚待补充，不以模拟响应代替。

### 前端与旧信息清理

弹窗与设置统一浅灰背景、白色卡片、玫粉强调色，支持浅色／深色／跟随系统。最初界面改版六区，新增词典后有七个分区：基础设置、翻译服务、网页翻译、视频字幕、快捷键、数据与高级、本地词典。旧 `#others` 映射到数据与高级，未知 hash 安全回基础设置；不因 UI 改版清除密钥。

商业参考是 [沉浸式翻译公开页面](https://immersivetranslate.com/zh-Hans/)。曾调研公开资料并复核计划，但没有完成安装 2026 商业插件的逐屏录屏对照。公开页面混有旧截图，因此不声称像素级一致或已逆向其闭源实现。

## 5. 已实现的视频字幕与限制

- 处理已有可读取文本字幕：原生 HTML5 TextTrack、YouTube 响应／DOM、DeepLearning.AI 的 Vidstack／VTT 路径。课程可见文字稿加逐句翻译入口，保留时间戳和跳转。
- 有完整时间轴时预取；只有 DOM 时处理当前字幕。共享优先队列并发 2，预取最多占一个槽；最多向前约 30 秒／12 条。暂停、后台及关闭状态限制工作。
- 每个播放器有会话；跳转、换轨、换视频／课程后丢弃过期结果，旧响应不能覆盖新字幕。字幕沿用网页所选服务与语言，新阅读路径不把译文持久化到磁盘。
- YouTube 独立双语按钮在原生 **CC 后、齿轮前**；没有 CC 时放齿轮前。菜单挂在播放器／全屏容器内向上展开，采用原生暗色菜单风格，样式放在子页。
- 用户明确报告“字幕功能可以正常使用”；自动化验证了轨道、菜单、全屏、取消等路径。真实 YouTube 曾出现字幕请求 HTTP 200 但正文为空，登录课程流程也未完整验收。
- 不是无字幕视频 ASR，不做 OCR、DRM／登录绕过，不承诺任意学习网站、所有语言和所有播放器。T-002／009／010 持续保留。

## 6. 本地词典与读音

### 产品形态和词库

这是浏览器扩展；若要本地词典／生词本，再安装 **Windows x64＋Chrome Native Messaging 伴随程序**和离线词库。伴随程序按需启动、SQLite 查询，不监听生产 HTTP 端口，不设开机启动；不是另一套完整桌面翻译器。Edge 的扩展加载不等于本地组件已对 Edge 验收。

免费数据采用 ECDICT 1.0.28（3,402,564 条记录）和中文维基词典英语扩展（97,019 条记录）。可能重叠，不能相加宣传独立单词数。ECDICT 为 MIT，维基词典有 CC BY-SA／GFDL 等来源约定；保留实际来源、版本、SHA-256 和逐条归属。扩展 MPL-2.0，新增伴随程序 GPL-3.0-only，分开交付许可及对应源码。

选词右键出现本地查词，网页词卡与完整词典页共用安全文本渲染；展示释义、音标、例句、词形、词源和相关词，取决于词条数据。保持有意义大小写与词形，例如 US／us、took→take，支持收录的词组。没有条目时明确提示，不自动转在线词典或模型。`customDictionary` 是原翻译替换／术语机制，与这里的本地词典不是一回事。

### 发音最终方案

用户原先希望离线真人录音；随后明确“停止下载真人录音”，并选择 **浏览器语音优先，另可配置 Google Cloud API**。浏览器按实际同口音可用音色选 Google／系统语音，支持英／美音和 0.75×。不能保证任意电脑都有 Google 英文音色。

Google Cloud 使用官方 Standard 接口，自配独立 Key、启用 API 与结算；费用和额度以服务方实时规则为准，本次交接未重新查价格。只有显式点击播放才发送当前词／短语与发音参数，不发送整页或 URL；失败明确显示，不静默换提供者。关闭／换词取消旧请求和声音，不持久化音频；音标仍来自本地词库，不承诺自动判定多音词语境。

**验收缺口：**上次真实 Chromium 只列出中文音色，没有英美音；没有真实 Cloud Key。因此缺音色提示、模拟 Cloud 解码播放与取消已测，真实英文播放、人工听辨和账户 API 调用未通过验收。以后先核对用户机器实际音色／配置，再继续 T-015，不通过下载已取消录音来“补齐”。

## 7. 生词收藏、复习与快捷键

### 用户操作

- 网页词卡星标、选词右键直接收藏、词典结果星标、词典右上角收藏计数和独立生词本页。
- 默认 **Alt+Q 查词／Alt+S 收藏**，在插件内直接录入、清除、恢复默认。Chrome 两个额外词典原生命令默认不绑定，作为可选入口。
- 先捕获新选区／坐标／原文语境，再聚焦词卡；新选区优先，无新选区时收藏可使用当前词卡。无内容只提示，不读剪贴板，不自动查询鼠标悬停词，不复用旧右键快照。
- 查词选区最多 120 个字符、8 个词；长句使用网页翻译，避免把整段误当词条。
- 即时显示进行中，收到本地写入确认再显示成功；同内容在途收藏合并、按住不连发；Esc／关卡不取消已经发出的收藏写入。输入、输入法与开放 Shadow DOM 编辑区受保护。
- 可选 Chrome 原生路径由当前标签页的焦点 document 一次认领并定向执行，避免 iframe、网页快捷键与原生命令重复。

### 数据和学习

独立 `favorites.sqlite3` 使用 WAL、事务与词头唯一约束，不依赖扩展 ID；更新／卸载程序、换词库、重置插件设置或清浏览器不应清掉收藏。保留词典释义快照及许可、可见原文语境、处理后的来源、首次／最近收藏时间、个人解释、标签、笔记和学习状态。已有收藏在词库缺失／损坏时仍可阅读和复习。

重复显式收藏按实际词头合并并追加语境，保留首次时间；编辑和复习不改变收藏时间。时间存 UTC、日期筛选按本地整日。URL 去账号信息、查询和片段，YouTube 仅保留必要 `v`；只在显式收藏时保存可见原文，不自动记录查词历史，隐身禁用收藏，无云同步。

每页 50 条，支持词语／日期／状态／标签／来源筛选和时间排序，兼容桌面、窄屏和深浅主题。翻卡使用当前筛选的固定集合与顺序，默认排除已掌握；Space 翻卡、1／2／3 评级，逐次持久化，跳过不增加次数。**尚无间隔复习调度。**

JSON v1 为完整一致备份，分片导出／导入；先校验再事务合并，重复导入保留本机已有学习进度、笔记和快照，异常整体回滚。已验证 5,001 条场景，不能宣称无限规模：标签最多 30 个／每个 40 字符，语境最多 200 条并有约 500 KB 总限，单语境 2,000 字符；快照与消息也有限额，导入文件上限 128 MiB。完整边界以 [词典文档](../LOCAL-DICTIONARY.md) 与校验代码为准。

真实用户生词本没有被写入测试词；测试使用隔离数据库。不得把测试桥接 HTTP 服务称为产品架构，也不得在后续验收中清空用户数据。后续超大生词本优化见 T-020。

## 8. 已出现的问题、证据与修复方式

### 8.1 下载 ZIP 时 IDM 报错

用户截图提示不能连接代理 `127.0.0.1:10808`。这是下载管理器使用的本机代理不可用，不能归因于翻译 API 或 ZIP 内容。处理思路是检查／修正 IDM 代理，或关闭该下载拦截后用浏览器直接下载；不要随意关闭防火墙或更改全局代理。发布阶段还曾碰到另一个不可用本机系统代理，采用单次命令 `-NoProxy`／`-Direct`，没有改全局网络设置。上述端口只是历史排障证据，不代表目前配置。

### 8.2 dc0e5e6 的 Build and test 失败邮件

全屏菜单测试曾因 `DOM.resolveNode: No node with given id found` 失败：CDP 前端节点编号跨全屏后失效。测试辅助器改为后端节点编号定位，修复提交 `da440ce`；该用例连续 10 次及当时全套 12 项浏览器测试通过，后续 CI 成功。保留失败历史，不关闭通知／删运行来隐藏问题。

### 8.3 Google 评论译文附加“合集、了解细节”

用户反复贴出一段关于夏凪、竹达与《鼓动》的日文 YouTube 评论和中文译文，指出末尾多出 UI 字词；用户确认引擎为 Google，未提供原视频链接。排查复现两种采集污染：隐藏说明／控件文字混入正文，以及行内评论节点向上查找到包含邻居元数据的祖先。

真实 Google 纯文本请求没有自动附加这些词；公开 YouTube DOM 确认评论正文可为行内 `#content-text`。修复 `78d5466` 排除隐藏／工具提示／控件文本，为显式站点正文限制边界，保留片段也做可见性过滤；自身仅译文包装用内部 WeakSet 识别，不信任网页可伪造标记。15 项浏览器回归及 CI 通过。**未拿到原反馈视频，不能断言当时具体污染节点已经定位；不能用全局删除“合集”等词修复。**详见 [排查说明](../YOUTUBE-TEXT-EXTRACTION.md)。

### 8.4 首次 Release 精简工作流失败

`6dbf4c6` 的 [39137618180](https://github.com/Yvonson/immersive-translate/actions/runs/39137618180) 因 Windows CRLF 与 Linux LF 的版权文本逐字节审计不同而停止；当次没有因此先删旧附件。`0184d8f` 对指定声明文本规范换行，二进制与数据继续精确 SHA 校验；[39137811264](https://github.com/Yvonson/immersive-translate/actions/runs/39137811264) 成功。邮件是某次自动流程失败通知，需要看 job／step，不能仅凭标题判断插件不可用。

### 8.5 发布审查发现并修复的缺陷

- 时钟回拨／未来时间导入导致最近收藏早于首次：最近时间至少为首次及已有最近时间，兼容修复旧异常行，不顺带改其他字段。
- 导入合并标签超过 30 个：校验并整批事务回滚，防止部分数据写入。

### 两次“还能做什么”调研的建议

完整研究是 [24 项功能机会](../research/FEATURE-OPPORTUNITIES-2026-10-18.md)，早期基线为 `f5b8bcb`。其中生词本、收藏和快捷键后来已实现，不能照旧表再当缺口；其他建议没有因用户提出调研而自动批准实施。

较适合后续选择的方向：

1. **视频学习侧栏与精听**：双语文字稿、搜索、点击跳转、字幕查词／收藏，上一句／下一句、单句或 A-B 循环、自动暂停、译文显隐。沿用现有时间轴，但需独立交互和真实站点验收。
2. **专业术语与语境质量**：全局／网站／课程词表，AI、编程、日常场景配置，跨字幕上下文和完整句对齐，配置变更使相关缓存失效。已有 `customDictionary`，不是从零添加替换。
3. **学习与导出**：今日复习／间隔复习、已知词标识、Anki TSV、整句和视频时间收藏、Markdown 课程笔记。现有固定顺序翻卡不等于间隔复习。
4. **显式语境解释**：选定词句后由用户选中的模型解释用法／长句，控制发送文本；不得静默把本地查词变在线调用。
5. **测量后提速**：分别测选择响应、IPC、SQLite、渲染和服务延迟，再优化缓存／去重／队列。快捷键减少操作步骤并不证明底层查询速度已经测量提升。
6. 后续可选：SRT／VTT 文件导入导出（已有解析器，缺完整用户流程）、输入框翻译预览与撤销、自有 PDF／EPUB、OCR、日语词库、画中画等。旧 PDF 外部转换入口不是完整本地保版 PDF 功能。

无字幕 ASR、会议／直播转写、发音评分、移动端和独立完整桌面应用成本更高，应独立定范围。项目没有承诺“完美复刻 2026 商业版所有功能”。
