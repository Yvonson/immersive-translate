# 项目记忆索引

本目录将影响后续开发的重要信息保存在版本控制中，供维护者和后续协作会话读取。根目录 [AGENTS.md](../../AGENTS.md) 是协作入口。

## 文档分工

| 文档 | 保存内容 | 更新时机 |
| --- | --- | --- |
| [PROJECT.md](PROJECT.md) | 用户目标、项目身份、长期约束与协作偏好 | 目标或约束变化时 |
| [STATUS.md](STATUS.md) | 当前实现、版本、验证证据和未验证范围 | 完成功能、修复、验收或发布时 |
| [DECISIONS.md](DECISIONS.md) | 带编号、日期、依据和影响的关键决定 | 做出或改变重要决定时 |
| [ROADMAP.md](ROADMAP.md) | 待办、完成标准及建议优先级 | 任务完成、发现问题或用户调整顺序时 |

## 阅读与更新规则

1. 开始任务先读项目背景和当前状态，再阅读相关决定与待办；结合实时 Git 状态及源码确认适用性。
2. 事实、用户要求、工程选择、待验证推测分别标明，不把建议写成用户批准的计划。
3. 状态记录使用 `YYYY-MM-DD` 日期，日期按项目所在地 Asia/Shanghai 理解。命令执行、CI、源码路径或提交是可用证据。
4. 只记录影响后续工作的摘要；详细实现留在开发文档，完整历史交给 Git。
5. 同一个事实只维护一处权威说明，其他文档通过链接引用。冲突时先核对用户最新要求与代码，再修正文档。
6. 决策编号递增且不复用。改变决定时新增记录，旧记录标明“已被 D-xxx 取代”；不要悄悄改写原始依据。

当前状态是有日期的快照，不保证远程平台和第三方接口永久维持相同状态。发布、网络能力等需要时重新验证。
