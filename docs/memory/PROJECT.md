# 项目背景

更新日期：2026-10-18。

## 用户目标

用户希望拥有自己的可持续改进的翻译项目，以老版沉浸式翻译源码为基础，实现网页双语翻译、视频字幕翻译，以及 Google、DeepSeek API 和本地模型接入。

用户明确要求：**重新初始化独立 Git 仓库，不在归档上游的分支或 GitHub Fork 关联下开发。** 决策依据见 [D-001](DECISIONS.md#d-001独立初始化仓库)。

## 本轮已确认范围

2026-10-17：用户已要求实施网页与字幕升级计划。只以 Chrome 为本轮目标；Ctrl 单按切换当前段落，保留原文并在下方呈现带行内格式的译文；修复快捷键配置；字幕沿用网页引擎及语言，提供播放器菜单及课程文字稿入口。只处理已有文本字幕，优先 YouTube、DeepLearning.AI 和通用 HTML5。不能把参考产品宣传或旧截图当作已经验证的 2026 行为。

2026-10-17 界面改版：用户选择 YouTube CC 旁独立图标、原生风格菜单；插件弹窗与设置页按浅灰/白卡片/玫粉重做并重新分区。旧赞助、收款及推广联系入口从当前源码、资源、文档和构建包中移除，保留许可证与必要来源。

版本：此前正式发布前冻结 `0.2.0` / `0.2.0-preview.1`；2026-10-18 用户明确要求发布并选择 v0.2.0 正式版，数字版本保持 0.2.0、移除 preview 后缀，见 D-014。实际发布状态以 STATUS 为准。

2026-10-17 本地词典：用户已确认并要求实施选词右键查词，英汉优先，释义、音标与例句安装资源后本地检索；用户随后要求停止真人录音下载，并选择默认浏览器语音、可选自配 Google Cloud API，见 D-011。首版 Windows x64＋Chrome，增加可选本地伴随程序和可下载资源，词卡与详细词典页用于学习释义、音标、例句和读音；不自动调用在线词典或翻译引擎补缺。

2026-10-18 本地生词本：用户确认词卡星标＋选词右键直接收藏，独立本机文件保存词条快照、原文语境和来源；同词归并、追加语境，保留首次／最近收藏时间。首版含日期／状态／标签／来源筛选、个人解释与笔记、翻卡复习和 JSON 备份，不含云同步或间隔复习算法。存储和兼容约定见 D-012。

2026-10-18 词典快捷键：用户希望减少右键菜单步骤，选择仅处理选词、Alt+Q 查词／Alt+S 收藏、插件内直接录入；收藏可兜底当前词卡，新选区优先。沿用本地组件和词库，不扩展到查询性能改造，见 D-013。
