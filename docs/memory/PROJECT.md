# 项目背景

更新日期：2026-10-17。

## 用户目标

用户希望拥有自己的可持续改进的翻译项目，以老版沉浸式翻译源码为基础，实现网页双语翻译、视频字幕翻译，以及 Google、DeepSeek API 和本地模型接入。

用户明确要求：**重新初始化独立 Git 仓库，不在归档上游的分支或 GitHub Fork 关联下开发。** 决策依据见 [D-001](DECISIONS.md#d-001独立初始化仓库)。

## 本轮已确认范围

2026-10-17：用户已要求实施网页与字幕升级计划。只以 Chrome 为本轮目标；Ctrl 单按切换当前段落，保留原文并在下方呈现带行内格式的译文；修复快捷键配置；字幕沿用网页引擎及语言，提供播放器菜单及课程文字稿入口。只处理已有文本字幕，优先 YouTube、DeepLearning.AI 和通用 HTML5。不能把参考产品宣传或旧截图当作已经验证的 2026 行为。
