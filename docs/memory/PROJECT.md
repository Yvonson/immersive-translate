# 项目背景

更新日期：2026-10-17。

## 用户目标

用户希望拥有自己的可持续改进的翻译项目，以老版沉浸式翻译源码为基础，实现网页双语翻译、视频字幕翻译，以及 Google、DeepSeek API 和本地模型接入。

用户明确要求：**重新初始化独立 Git 仓库，不在归档上游的分支或 GitHub Fork 关联下开发。** 决策依据见 [D-001](DECISIONS.md#d-001独立初始化仓库)。

## 协作偏好

- 使用中文说明结果、限制及下一步。
- 用户希望主动推进已授权的项目工作，明确表示可以提供必要权限；这不替代工具权限要求，也不构成对任意未来高影响操作的授权。
- 用仓库文档维护重要记忆，让后续开发可以接续已有决定与验证记录。

## 长期约束

- 保留来源、许可证和版权说明。
- 不提交本地上游 Git 元数据备份、API Key、认证材料、`node_modules/` 或 `dist/`。
- 翻译服务由用户选择，密钥及数据处理遵循 [PRIVACY](../../PRIVACY) 与 [开发说明](../DEVELOPMENT.md)。
- 未完成的能力与未经验证的兼容性必须如实标注；自动化模拟测试与真实浏览器/API 验收分开记录。
