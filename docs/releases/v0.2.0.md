## 本次内容

- 保留原文，译文在段落下方继承字体与格式；鼠标悬停段落单按 Ctrl 切换，整页翻译默认 Alt+Shift+T。
- Google／Yandex、自己的 DeepSeek API 或本地／自定义兼容模型。字幕使用同一引擎与目标语言；错误不自动转发另一家服务。
- 分区设置、浅深主题、播放器内字幕菜单；YouTube 图标紧邻 CC，支持样式配置及受限字幕预取。
- Windows x64＋Chrome 离线英汉释义、音标、例句；Alt+Q 选词查询、Alt+S 收藏，支持设置按键、词卡兜底与 iframe。
- 本地生词本保存解释快照和语境，按时间、状态、标签和来源筛选；个人笔记、翻卡复习及 JSON 备份恢复。
- 浏览器语音优先，另可自行配置 Google Cloud 官方 TTS。只在点击时发送当前词语；不下载真人录音或离线声音模型。
- 移除旧赞助、收款、邀请入口和相关资源，保留原许可证、版权及来源。

## 发布审查修复

- 收藏遇到系统时间回拨时保持首次／最近日期顺序，并修复预览版受影响的本地行；导入合并超过 30 标签时完整回滚，避免生成无法恢复的备份。
- 旧翻译入口不再根据语言自动切换服务；通用配置不加载语音密钥。
- 替换旧 Gulp／Babel 构建工具链，npm 审计从 28 项降至 0；扩展包包含许可证、来源、隐私说明及提交信息，逐文件检查 ZIP 与安装目录一致。
- 所有原始词库固定 SHA-256，构建前校验，资源清单完整保留来源，避免复用旧工作数据库。附组件对应源码、词库清单、校验和安装指南。

## 验证和支持边界

24 项扩展单元、16 项 Python、27 项 Chromium 浏览器回归，以及 Windows 实际安装／升级验证通过。此次只重新分组，完整包内每个扩展／程序文件和词库均比对原发布的 SHA-256，没有重新编译或更换数据。词库下载约 254 MiB，安装约 889 MiB；记录来自 ECDICT 和中文维基词典，可能重复。

字幕仍为实验适配，只翻译已有可读文本，不提供无字幕语音识别或绕过登录／DRM。真实模型、Cloud 语音和课程的未验收范围见 [审查记录](https://github.com/Yvonson/immersive-translate/blob/main/docs/RELEASE-REVIEW-2026-10-18.md)。本次未上架浏览器商店。
