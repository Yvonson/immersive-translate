安装：扩展管理页启用开发者模式，加载解压后的扩展；Windows 完整包选择其中的 **chrome/**。本地词典再按包内 **INSTALL.md**，在 **companion/** 注册程序并导入随包词库。

[详细安装指南](https://github.com/Yvonson/immersive-translate/blob/main/docs/INSTALL.md) · [Google／DeepSeek／本地模型配置](https://github.com/Yvonson/immersive-translate#readme)

本版包含网页双语、Ctrl 段落翻译、视频字幕菜单、本地词典、生词收藏及 Alt+Q／Alt+S 快捷键。此次调整分发包装和命名，版本仍为 0.2.0；已安装用户无需为整理重装。

字幕仅翻译已有文本，仍为实验功能。本地词典验证范围为 Windows x64＋Chrome；其他平台、真实模型／Cloud 语音的未验收范围见 [验证记录](https://github.com/Yvonson/immersive-translate/blob/main/docs/RELEASE-REVIEW-2026-10-18.md)。
