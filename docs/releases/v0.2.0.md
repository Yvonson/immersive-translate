# Open Bilingual Translate v0.2.0

独立开源浏览器插件：网页双语阅读、实验性视频文本字幕翻译、本地英汉词典和生词学习。数字版本保持 **0.2.0**，移除预览显示后缀；无需本项目账号或订阅。

## 下载与使用

- **只翻译网页／字幕**：下载附件 `chrome.zip`，解压，在 Chrome 扩展管理页以开发者模式加载含 `manifest.json` 的目录，刷新网页。
- **还要本地词典／生词本**：额外下载 `dictionary-companion-windows-x64.zip` 和 `dictionary-core.zip`。完整解压组件，按扩展“全部设置 → 本地词典”提供的当前 ID 命令安装，在管理窗口导入词库，然后重新连接。
- **从预览版更新**：覆盖原扩展目录后重新加载；Windows 组件也需更新，已有词库可沿用。先按需导出生词本 JSON，程序和词库升级保留独立的个人收藏。

[逐步安装指南](https://github.com/Yvonson/immersive-translate/blob/v0.2.0/docs/INSTALL.md) · [引擎配置与完整说明](https://github.com/Yvonson/immersive-translate/blob/v0.2.0/readme.md)

## 本次内容

- 保留原文，译文在段落下方继承字体与格式；鼠标悬停段落单按 Ctrl 切换，整页翻译默认 Alt+Shift+T。
- Google／Yandex、自己的 DeepSeek API 或本地／自定义兼容模型。字幕使用同一引擎与目标语言；错误不自动转发另一家服务。
- 分区设置、浅深主题、播放器内字幕菜单；YouTube 图标紧邻 CC，支持样式配置及受限字幕预取。
- Windows x64＋Chrome 离线英汉释义、音标、例句；Alt+Q 选词查询、Alt+S 收藏，支持设置按键、词卡兜底与 iframe。
- 本地生词本保存解释快照和语境，按时间、状态、标签和来源筛选；个人笔记、翻卡复习及 JSON 备份恢复。
- 浏览器语音优先，另可自行配置 Google Cloud 官方 TTS。只在点击时发送当前词语；不下载真人录音或离线声音模型。
- 移除旧赞助、收款、邀请入口和相关资源，保留原许可证、版权及来源。

## 发布审查修复

- 收藏遇到系统时间回拨时保持首次／最近日期顺序，并修复预览版受影响的本地行；导入合并超过 30 标签时完整回滚，避免生成无法恢复的备份。
- 旧翻译入口不再根据语言自动切换服务；通用配置不加载语音密钥。
- 替换旧 Gulp／Babel 构建工具链，npm 审计从 28 项降至 0；扩展包包含许可证、来源、隐私说明及提交信息，逐文件检查 ZIP 与安装目录一致。
- 所有原始词库固定 SHA-256，构建前校验，资源清单完整保留来源，避免复用旧工作数据库。附组件对应源码、词库清单、校验和安装指南。

## 文件和验证范围

词库含 ECDICT 3,402,564 条与中文维基词典英语扩展 97,019 条记录，可能重复，不等于独立词数；下载约 **254 MiB**，安装约 **889 MiB**，精确数据见附件 `catalog.json`。GPL 组件源码见 `dictionary-companion-sources.zip`；`zhwiktionary.jsonl.gz` 是开发者重建用原始快照，普通用户不用下载。扩展为 MPL-2.0，组件 GPL-3.0-only，词典数据按各来源许可交付。

验证包含 24 项扩展单元测试、16 项 Python 回归、27 项 Chromium 浏览器回归、构建／ZIP 检查，以及 Windows 本地组件与隔离收藏升级验证。真实网站、真实收费 API 与模拟测试分开记录，详见 [审查记录](https://github.com/Yvonson/immersive-translate/blob/v0.2.0/docs/RELEASE-REVIEW-2026-10-18.md)。

字幕仍为实验适配，仅翻译已有可读文本，不支持无字幕语音识别、OCR 或绕过登录／DRM。真实 DeepSeek／本地模型／Google Cloud 端到端及英美音人工听辨尚未全部验收；配置与网络条件由用户决定。Firefox 128+ 为未签名开发包，未完成本项目功能验收；本地词典首版仅验证 Windows x64＋Chrome。GitHub Release 分发手动安装包，本次没有上架浏览器商店。
